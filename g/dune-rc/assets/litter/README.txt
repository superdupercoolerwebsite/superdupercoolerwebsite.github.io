Drop 3D model files here to replace the simple built-in litter shapes.
Name each file after the kind of litter, in .glb format, for example: can.glb, tyre.glb, trolley.glb

Kinds: can, pbottle, gbottle, cup, box, brick, tyre, plank, flipflop, sunglasses, phone, butt, rope, trolley, battery,
       keys, wallet, watch, camera, headphones, teddy, football, drone

The game scales each model to its real-life size automatically. Refresh the page after adding files.
